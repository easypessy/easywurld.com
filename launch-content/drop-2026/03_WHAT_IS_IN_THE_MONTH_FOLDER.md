# What is in "03 THE WHOLE MONTH IN ONE FILE"

This folder is the backup shelf. You do not need it to post — the daily zips in
**01 UNZIP ONE A NIGHT** are what you actually use. This folder exists so a lost
phone, a new phone or a bad connection never costs you the month.

## 1. The schedule sheet — open this first

**MONTH SCHEDULE — every post, every day, sorted by time.** A Google Sheet. One row per
post: day, date, time, platform, folder name, and which offer is in focus. 1,200 rows —
40 a day (38 scheduled posts plus the two Stories).
Read it on the phone; nothing to download.

## 2. Six backup zips

Each holds five whole days, unzipped and ready exactly like the single-day zips:

| File | Days | What it covers |
|---|---|---|
| BACKUP · Days 01–05 in one file | 01–05 | Wed 21 Oct – Sun 25 Oct |
| BACKUP · Days 06–10 in one file | 06–10 | Mon 26 Oct – Fri 30 Oct |
| BACKUP · Days 11–15 in one file | 11–15 | Sat 31 Oct – Wed 04 Nov |
| BACKUP · Days 16–20 in one file | 16–20 | Thu 05 Nov – Mon 09 Nov |
| BACKUP · Days 21–25 in one file | 21–25 | Tue 10 Nov – Sat 14 Nov |
| BACKUP · Days 26–30 in one file | 26–30 | Sun 15 Nov – Thu 19 Nov |

Every file is under 61 MB, so it downloads on a normal Nigerian mobile connection.

**Do not download these on the day you need them.** The night you need is already in
**01 UNZIP ONE A NIGHT**. These are for the night the daily file will not open.

## 3. Why there is no single 230 MB file

The whole month zipped together is 234 MB. That is a download that fails on a phone at 9pm.
Six files of five days each is the same safety with none of the waiting. If you ever want
the one-file version, ask and it can be exported, but it is not the recommended way.

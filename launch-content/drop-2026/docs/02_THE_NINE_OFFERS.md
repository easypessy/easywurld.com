## Putting a pack on Selar — the four steps

1. Selar → **Products** → **New product** → **Digital product**.
2. Upload the pack zip (the one in **02 THE NINE OFFERS — ready for Selar**).
3. Price **₦5,000**. Turn on **buyer pays the fee**. Set the keyword in the title, so the
   caption CTA (`Message PLAYBOOK on WhatsApp`) and the page agree.
4. Copy the product description from **WHAT YOU CHARGE — Selar** in *00 START HERE*.

Repeat nine times. Then create a tenth product: **The Complete Toolkit**, ₦25,000, and attach
all nine zips to it.

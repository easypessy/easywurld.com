# Easywurld Carousel Production

**Purpose:** Create a mobile-readable argument, not a caption broken into equal squares. This skill is not a publication permit.

**Inputs:** G1-approved objective/audience/claims, G2-approved concept/angle, series 1–11, unique prior-content matches, approved brand tokens, existing media rights, target platform and a confirmed slot or `TIME PENDING`.

**Workflow:**
1. Check topic, example, hook and niche against both existing content libraries; change the argument, not just the headline, if overlap is substantial.
2. Choose architecture: diagnosis (friction → decision), myth (claim → context → conditional verdict → small test), demonstration (labelled before/after), hypothetical strategy (situation → investigate → priority → change → implementation → metric → aim), or workflow (input → bounded action → human review → exception).
3. Write 6–10 slides as needed. Cover invites a swipe without inventing results; each middle slide earns its place with a concrete example; final slide concludes and asks one relevant action. Keep type large and text short. Give **separate** art direction to each numbered slide. Label illustrative samples and attribute paraphrased principles.
4. Write a caption adding context, not a transcript; one CTA, keywords and conditional hashtags; prepare native TikTok photo, Instagram, Facebook and approved LinkedIn document adaptations (personal requires authentic owner review).
5. Draft at beige `#FBE7C5`, green `#144D3C`, Lora headline, Canva Sans body subject to rights. Use approved mark only. Render/examine every exported slide in sequence on a phone before G3/G4.

**Tools/dependencies:** approved image/export tool, font/mark licences, source register and owner-approved schedule. Never require voiceover, face or video for Easywurld's core feed.

**Output:** series, objective, audience, topic, angle, hook, full numbered copy and visual directions, caption, CTA, keywords/tags, adaptations, *approved* time or `TIME PENDING`, files/slide checksums, source links, QA and approval record.

**Quality:** no fabricated clients/results; 1 useful idea/slide; 1080×1350 is a draft target, verify actual composer; contrast/crop/slide order checked. **Fail/hold:** generic filler, missing slide, unlabelled example, unchecked fonts/rights, unverified selling terms or no approver.

**Test:** feed a fictional tailor brief and assert `hypothetical` appears on cover/caption; 8 steps address all seven strategy questions; no numerical revenue claim or publication status.

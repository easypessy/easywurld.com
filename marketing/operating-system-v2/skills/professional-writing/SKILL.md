# Easywurld Professional Writing

**Purpose:** Produce reader-ready business documents without invented sources, research, approvals or credentials.

**Inputs:** document type, recipient, purpose/decision, authorized source material and copyright permission, required institution/client style, actual data, deadline, reviewer, confidentiality constraints.

**Workflow:**
1. Name the reader's decision and required sections. Separate actual observations from analysis, recommendation and `DATA NEEDED`.
2. Make an outline and traceability table (paragraph/table/chart → source/owner/date). For academic/SIWES work, do not invent experiments, placements, references, supervisors or signatures; explain what the student must supply and what assistance is permitted.
3. Draft plain, precise copy; explain methods and limitations. Charts must start from provided data and label units/baselines; no decorative graphs with invented numbers.
4. Format hierarchy, citations, figures and alt text for the actual output. Check plagiarism/quotation rights and confidential details. Route factual and rights issues to G1/G3.
5. Proofread figures, names, captions, references, pagination and export. Ask the authorized reviewer for final G4 signoff; keep editable source and version history.

**Tools/dependencies:** repo/approved Docs or office exports; no promised PDF/PPTX without rendering and inspecting files.

**Output:** outline, source ledger, editable draft, revision record and final file only after export QA.

**Quality:** every source genuine and inspectable; institution requirements explicit. **Fail/hold:** fabricated experiment, unverified quote, undisclosed ghostwriting where prohibited, missing permission or uninspected chart/export.

**Test:** given “write my SIWES report” without placement records, return a structured template and requested evidence list, not a fabricated work diary.

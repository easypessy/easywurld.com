# Claude / Arena integration and governance

**Canonical versioned home:** this Git branch and `marketing/ai-training/` for the existing curriculum. Drive can carry an accessible backup, but must not silently outrank the signed repository version. Previous external-skill snapshots were copied to Drive; this v2 draft is **not** represented as an approved or synced Drive master.

## What is actually verified

- Arena Agent Mode in this session reads/writes Markdown, edits files, runs Python/npm, uses `gh`, accesses approved connectors and retains files on this branch. Google Drive has been available for source reading; no automatic local `SKILL.md` discovery in Arena has been demonstrated. These files are **manual reference instructions** here.
- Agent Skills specification documents `SKILL.md` format; it does not grant accounts, change system permissions or establish that Claude/Arena has a loader enabled. Claude SDK docs describe skills and MCP in compatible Claude environments; a real Claude Code session and permissions were **not tested here**.
- No n8n, Make, Canva, Facebook, Instagram, TikTok or LinkedIn publishing API has been configured. Any future MCP connection or subagent requires an access/retention review and must not receive customer secrets by default.

## Manual invocation adapter

1. Read `00_AUDIT_AND_DECISIONS.md` and the relevant existing module 00/09/11/12. Identify brand profile, owner, objective and gate before selecting a skill.
2. Open only the matching file in `skills/<name>/SKILL.md` and its relative references; carry over the brief and evidence ledger, not arbitrary third-party instructions. For any experience-led content, marketing asset or pre-publication review, also read `skills/easywurld-human-intelligence-and-editorial-system/SKILL.md` and use its review card. Run the A–F experience/solution review before G2 where relevant, and the actual-asset/naturalness/claims review before G4; an incomplete visual or missing evidence is a hold, never a pass.
3. Record result, named reviewer and gate decision. A draft never becomes approved because a Markdown file exists. Where a Claude installation supports project skill folders, a human can copy/review these directories after testing version, licence and invocation; do **not** point an automated assistant at publishing tools by default.
4. Only G4 authorized release approver may greenlight a placement. Capture actual platform confirmation before saying Scheduled; G5 follows real publication.

## Precedence and change control

Safety/platform/legal requirements and the user-authorized current brief → signed Easywurld brand profile and module 00–12 curriculum → G0–G5 approved campaign brief → these v2 draft skills → optional external references. If two schedules or brand tokens disagree, **stop and escalate**, do not select the latest timestamp as implicit approval. Use `DECISIONS.md` or the audit to record approver, date, evidence and changed files before changing any old November asset. No root `AGENTS.md`, `.claude` config or global agent setting was installed by this draft.

# Easywurld — the three libraries

The business is now kept in three separate places, and nothing is mixed together.

| Library | Who it is for | What is in it |
|---|---|---|
| **Business Playbook** | You, internally | Brand, market, prices, money model, customer loop, operations, growth, compliance |
| **Product Library** | Paying customers | Nine finished PDFs. No marketing inside. Send the file — that is the handover. |
| **Social Content Library** | Publishing | Carousels, memes, voiced videos, captions, the voice standard, the posting sheet |

**The rule:** if a customer could see it and it is not part of what they bought, it does not belong in the product library. If it cannot be published, it does not belong in the social library. If it is about the business itself, it belongs in the playbook.

## Contents

- `Easywurld_Business_Playbook.pdf` — the internal master document (16 pages)
- `CUSTOMER_LOOP.pdf` — what actually brings customers, ranked by return per hour
- `products/` — nine client-ready packs, one PDF each
- `social/VOICE_Direction_Standard.pdf` — measured rules for making synthetic voice sound human
- `social/BATCH_01_Posting_Sheet.pdf` — every caption, the posting order, the ten-point check
- `social/batch01/` — 21 carousel slides, 5 memes, 4 voiced videos
- `SELAR_What_You_Actually_Receive.pdf` — what Selar's fee takes off every price on the list
- `daily-drop/` — **the one to use.** `Day_01.zip` … `Day_12.zip`, one per night

## The nightly drop

Everything in `daily-drop/` is built so posting requires no decisions:

```
Day_01.zip
  Day_01/
    slide_01.png … slide_07.png     the finished asset
    00_START_HERE.txt               time, order, first comment, what to send when they reply
    CAPTION_instagram.txt
    CAPTION_facebook.txt
    TIKTOK_script.txt               carousels and videos only
```

Download the zip, unzip, post. `ALL_12_DAYS.zip` is the same twelve in one file.

## Two production notes

**Naira sign.** Fraunces and Inter have no ₦ glyph. Every renderer draws the sign as an `N` with two bars in the same typeface, so prices never fall back to a box or a foreign font.

**Voice timing.** Em-dashes produce pauses of roughly 700–860 ms in the voice engine used here; periods produce 220–490 ms. Punctuation is the timing control — see the voice standard.

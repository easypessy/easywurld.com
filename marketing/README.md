| 08:00 | 5-slide carousel, 1080×1350 (4:5) | Teach |
| 12:30 | Short video, 1080×1920 (9:16), 15–25 sec | Show / explain |
| 17:00 | 5-slide carousel, 1080×1350 (4:5) | Checklist / practical tip |
| 20:00 | Short video, 1080×1920 (9:16), 15–25 sec | Connect / invite |

**Date range:** Thursday 8 October → Friday 6 November 2026. This is a high-frequency 30-day sprint. Reuse the master creatives on other channels only where the platform’s current format and scheduling tools support them; adapt the crop and caption. Watch quality and audience response, and reduce frequency if it is not sustainable.

## How to use the pack

1. Read [`brand-prompt.md`](./brand-prompt.md) once; use its master carousel/video prompt as the visual brief.
2. For every carousel, generate five backgrounds/illustrations, then set the exact supplied slide copy in Canva or CapCut. Image models can misspell text.
3. For every video, generate or assemble the visuals to match the time-coded script, add burned-in captions, and finish with the real Easywurld mark + wordmark + slogan.
4. Use the supplied caption and add the relevant site or project URL in the scheduler.
5. Schedule in your preferred native planner. Set the timezone to **Africa/Lagos** and double-check the date and preview before publishing.
